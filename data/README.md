# Data

**Dataset:** Ames Housing, from Kaggle's
[House Prices: Advanced Regression Techniques](https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data).

## How to get it

1. Download `train.csv` (and `data_description.txt`, which explains every column) from the Kaggle page.
2. Place them in `data/raw/`.
3. Run `make data` to create the fixed train/test split in `data/processed/`.

## Rules

- `data/raw/` is read-only: never edit these files.
- `data/processed/` is generated by code and can be deleted and rebuilt.
- Data files are git-ignored; only the instructions live in the repo.
